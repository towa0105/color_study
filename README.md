# color_study

2年クリエイティブワーク後期制作作品です。

React + TypeScript + Vite で作成したWebアプリです。

## 開発環境

- Node.js 20.19+ または 22.12+
- npm

## 起動方法

```bash
npm install
npm run dev
```

表示されたURL（通常は http://localhost:5173/）をブラウザで開いてください。
画面を編集する場合は `src/App.tsx` と `src/App.css` を変更します。

## コマンド

```bash
npm run dev      # 開発サーバーを起動
npm run build    # 型チェックと本番用ビルド
npm run lint     # lint
npm run preview  # ビルド結果をローカルで確認
```
